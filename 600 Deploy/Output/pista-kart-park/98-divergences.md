# 98 — Divergências

Nenhuma linha `open` abaixo é um defeito do artefato: cada uma é algo que a política do estágio exige da release e que o
repositório, hoje, não pode fornecer sem uma decisão ou uma ação humana. Nenhuma contribui para o veredito; cada `open` bloqueia
uma precondição do `runbook.md` até ser resolvida. Uma linha `resolved` nomeia o que a resolveu e fica como histórico. Uma linha
`waived` é uma divergência **decidida** pelo dono do produto, com a decisão e a data nomeadas; não bloqueia nada. Uma linha
`blocked` é uma exigência do estágio que o **projeto validado** da feature suspende por decisão registrada — aqui, a promoção. As
linhas herdadas das releases anteriores (`600 Deploy/Output/modelo-kart-01/98-divergences.md`) são recitadas com o seu estado
de hoje, porque o site, o pipeline e a política de ramos são os mesmos.
